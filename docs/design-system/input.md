# Input / Textarea

**Import:** `@/components/ui/Input`

## Variants

`default` | `error` · sizes `sm` | `md` | `lg`

## Do / don’t

- **Do** wrap with `Field` for label + hint + error
- **Don’t** restyle with gray border utilities

## A11y

Pair with `Label` / `htmlFor`. Use `variant="error"` with `Field` `error` text (`role="alert"`).
