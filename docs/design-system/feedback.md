# Feedback

**Import:** `@/components/feedback`

| Component | Use |
|-----------|-----|
| `EmptyState` | No results / empty lists |
| `ErrorState` | Failed fetch with optional `onRetry` |
| `LoadingState` | Full-section loading with Spinner |
| `Alert` | Inline messages |

Toasts remain via `showToast` / `ToastHost` (tokenized colors + `--z-toast`).
