# Alert / Spinner / Divider / IconButton

| Component | Notes |
|-----------|--------|
| Alert | tones: `info` `success` `warning` `danger` `neutral`; `role="alert"` |
| Spinner | sizes `sm` `md` `lg`; `role="status"` |
| Divider | optional `label` |
| IconButton | requires `aria-label`; variants `ghost` `soft` `outline` `danger` |
